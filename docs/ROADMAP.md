# Roadmap

The roadmap is phased to ship a credible marketplace first, then deepen engagement, then add premium and high-cost features.

## Phase 1 — MVP

The minimum needed to onboard creators and run a working marketplace.

- Landing page
- Authentication
- Creator profiles + application flow (the access gate)
- Project marketplace (post and apply to roles)
- Admin dashboard (review applications, moderate listings)

### Current status

**Phase 1 is complete**, and most of Phase 2 has shipped alongside it.

**Done**
- Landing page, authentication, Pro/Fan account-type routing and app shells.
- Pro profiles, onboarding and the approval gate; admin dashboard for applications, content and projects.
- Project marketplace: browse with filters, per-role applications, and posting with roles, pay ranges, types and tags.
- Messaging, social feed with connections and endorsements, classes with enrolments and reviews, events, articles, and saved items.

**Next**
- Finish restyling the remaining surfaces to the Callboard design (`/projects/mine`, `/network` below the fold).
- Make project creation atomic (see docs/DECISIONS.md).
- Live nav counts beyond Network, and notifications.

## Phase 2 — Engagement

Turn the marketplace into a network people return to.

- Account-type-aware routing (separate Pro and Fan app shells)
- Fan home/app — follow-only feed, Discover, Events, Read
- Messaging
- Social feed
- Reviews
- Notifications
- Events
- Classes directory
- Articles (entertainment news)

## Phase 3 — Scale & premium

Higher-cost and revenue features once the network has traction.

- Video audition uploads
- Advanced search
- Premium memberships
- Mobile apps
